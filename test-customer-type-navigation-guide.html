🧭 Customer Type Management - Navigation Guide

📍 Where to Change Customer Types & MSXpert Access

You need to go to the Customer Types tab within the Permissions section, not the main User Management tab.

✅ Correct Navigation Path

Step 1: Login as admin
Step 2: Go to Admin Dashboard
Step 3: Click "Permissions" tab
Step 4: Click "Customer Types" tab (4th tab)
Step 5: Use the sub-tabs:
  • User Management: Edit customer types and user info
  • MSXpert Access: Control MSXpert permissions
  • Overview: View statistics
Admin Dashboard → Permissions → Customer Types → User Management

⚠️ Common Confusion

❌ Wrong Place (Can't Change Customer Types):

Admin Dashboard → User Management
  • Shows all users from database
  • Can edit roles (USER, ADMIN, etc.)
  • Can block/unblock users
  • ❌ Cannot change customer types
  • ❌ Cannot manage MSXpert access

✅ Right Place (Can Change Everything):

Admin Dashboard → Permissions → Customer Types
  • Shows users with customer type data
  • Can edit roles (USER, ADMIN, etc.)
  • ✅ Can change customer types
  • ✅ Can manage MSXpert access
  • ✅ View statistics and overview

🎯 What You Can Do in Customer Types

Overview Tab:
  • View total users count
  • See MSXpert access statistics
  • Customer type distribution charts
  • Most common customer type
User Management Tab:
  • Search and filter users
  • Change customer types (SPRINGER ↔ WILEY ↔ F1000 ↔ DMP)
  • Edit user names and roles
  • Toggle MSXpert access
  • View last updated timestamps
MSXpert Access Tab:
  • Dedicated MSXpert permission management
  • Toggle access for individual users
  • Admin auto-access (cannot be disabled)
  • Clear access status indicators

🔧 How to Change Customer Types

Step 1: Navigate to Customer Types section
Admin Dashboard → Permissions → Customer Types
Step 2: Click "User Management" tab
Step 3: Find the user you want to modify
Step 4: Click the "Edit" button for that user
Step 5: In the modal:
  • Change Customer Type dropdown (SPRINGER, WILEY, F1000, DMP)
  • Toggle MSXpert Access switch
  • Update Role if needed
  • Modify Name if needed
Step 6: Click "Save Changes"
Step 7: ✅ Changes are applied immediately!

🎉 You're All Set!

Now you know exactly where to go to manage customer types and MSXpert access:

Admin Dashboard → Permissions → Customer Types → User Management → Edit User

This is the only place where you can change customer types and MSXpert access permissions!
