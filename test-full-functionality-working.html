🚀 New Backend API Endpoints

1. Update Customer Type:
PUT /api/admin/users/{userId}/customer-type
Body: { "customerType": "SPRINGER" | "WILEY" | "F1000" | "DMP" } Response: { "success": true, "data": { "id": "user-id", "email": "user@example.com", "userType": "WILEY", "updatedAt": "2024-01-20T10:30:00Z" }, "message": "Customer type updated to WILEY" }
2. Update MSXpert Access:
PUT /api/admin/users/{userId}/msxpert-access
Body: { "msxpertAccess": true | false } Response: { "success": true, "data": { "id": "user-id", "email": "user@example.com", "msxpertAccess": true, "updatedAt": "2024-01-20T10:30:00Z" }, "message": "MSXpert access granted" }

🧪 How to Test the Full Functionality

Step 1: Start the backend server
cd backend && npm start
Step 2: Start the frontend
npm run dev
Step 3: Navigate to Customer Types
http://localhost:8081 → Admin Dashboard → Permissions → Customer Types
Step 4: Look for the success alert

You should see: "Fully Functional: Changes to customer types and MSXpert access are now saved to the database!"

Step 5: Test customer type changes
  • Click "User Management" tab
  • Click "Edit" on any user
  • Change customer type (e.g., SPRINGER → WILEY)
  • Click "Save Changes"
  • ✅ Success toast: "User Updated Successfully"
Step 6: Test MSXpert access toggle
  • Click "MSXpert Access" tab
  • Toggle the switch for any user
  • ✅ Success toast: "MSXpert Access Updated"
Step 7: Verify persistence
  • Refresh the page (F5)
  • ✅ Changes should persist!
  • Customer types remain changed
  • MSXpert access settings remain changed
